# Hi, I'm Dilara 👋

I am a lecturer and researcher working on **mathematical modeling in subsurface hydromechanics**, **porous media flow**, and **numerical methods** for scientific and engineering applications.

My research focuses on mathematical and numerical modeling of subsurface fluid flow, with particular interest in computational methods for porous media problems.
